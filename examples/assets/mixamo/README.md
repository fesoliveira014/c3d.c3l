# Mixamo character

`examples/mixamo` loads `character.fbx` from this directory when run without a path. Download any
character from [Mixamo](https://www.mixamo.com) with an animation applied, using:

- Format: FBX Binary (.fbx)
- Skin: With Skin
- Frames per second: 30
- Keyframe reduction: none

Save it here as `character.fbx`. Git ignores every `.fbx` file in this directory: Mixamo assets are
governed by Adobe's terms and are not redistributed with this repository.
